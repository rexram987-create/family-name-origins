# שורשי המשפחה — Family Name Origins

מילון מחקרי בעברית לשמות משפחה, למשמעויותיהם ולרקע ההיסטורי והלשוני שלהם. הפרויקט כולל שמות מקהילות יהודיות ומקבוצות נוספות, ומקפיד להבחין בין פירוש מילוני, מסורת משפחתית והשערה שאינה מאומתת.

**אתר:** https://family-name-origins.vercel.app/  
**מאגר GitHub:** `rexram987-create/family-name-origins`

## מצב הפרויקט — 21 באוקטובר 2026

- **192 רשומות** בקובץ `data/surnames.json`.
- מצב מחקר ברשומות: **108 `verified`**, **3 `review`**, **81 `unknown`**. הסיווג מתייחס לרמת התיעוד ברשומה, **לא** להוכחת שושלת משפחתית; גם ברשומות `verified` יש מקורות שעדיין דורשים הצלבה עצמאית.
- אתר Vite בעברית, בכיווניות RTL, עם עיצוב כהה וטקסט מוגדל לנוחות הקריאה בנייד.
- דף בית עם חיפוש; מילון שמות עם חיפוש בעברית ובאותיות לטיניות, מיון אלפביתי וסינון לפי אות ראשונה; דף פרטים לכל שם; ודף הסבר כללי על היווצרות שמות משפחה.
- בכל דף שם: פירוש קצר, רקע תמציתי, סטטוס אימות, שפת מקור, קהילות היסטוריות, קשר גאוגרפי כאשר ידוע, כתיבים חלופיים, הערות וקישורים למקורות.
- הקוד והנתונים מעודכנים ב־GitHub. האתר נפרס ב־Vercel; אין לראות בעצם העדכון במאגר אישור שבוצעה בדיקת פריסה חדשה.

## עקרונות המחקר והעריכה

1. **תמציתיות:** פירוש קצר וברור ורקע קצר, ולא ערך אנציקלופדי.
3. **מקור ניתן לבדיקה:** לכל טענה מחקרית יש לצרף קישור מתאים; אין להציג השערה כעובדה.
4. **הבחנה בין מקורות:** אותו מילון המופיע בכמה אתרים אינו נחשב לכמה מקורות עצמאיים. מקור כללי אינו שקול לערך ייעודי לשם מסוים.
5. **זהירות באטימולוגיה:** שמות דומים, תעתיקים קרובים ומשמעויות דומות אינם מוכיחים זהות שם או קרבה משפחתית.
6. **ללא קביעת מוצא אישי:** שם משפחה לבדו אינו מוכיח מוצא, השתייכות לקהילה, כהונה, לוייה או שושלת.
7. **מסורות בעל פה:** ניתן לתעד מסורת משפחתית במפורש כמסורת, בלי להפוך אותה לאטימולוגיה מאומתת. למשל, לגבי **חרלופסקי** מתועדת המסורת המשפחתית ״גן של אור״, אך הפירוש **אינו מאומת אטימולוגית**.
7. **זכויות שימוש:** אין להעתיק מאגרי צד שלישי ללא הרשאה או רישיון מתאים; מציגים תקצירים עצמאיים וקישורים למקורות.

## מחקר חברי הכנסת הראשונה — התקדמות

המאגר הורחב גם לשמות המשפחה של חברי הכנסת הראשונה. המחקר מתנהל בהדרגה: מאתרים את שם המשפחה המקורי ואת כתיביו ההיסטוריים, בודקים את משמעותו במקורות אטימולוגיים, משווים לשם העברי החדש ומנסים למצוא תיעוד לסיבת שינוי השם.

- **מקורות מרכזיים:** מאגר שמות המשפחה של מוזיאון אנו, מילוני שמות משפחה, הספרייה הלאומית, ארכיונים וביוגרפיות היסטוריות.
- **דוגמאות לשינוי שם מתועד:** יערי (ואלד), בן־צבי (שמשלביץ׳), סנה (קליינבוים), ארן (אהרונוביץ׳), לביא (לבקוביץ׳), ארגוב (גרבובסקי), אסף (וילקומיץ׳), ובהיר (גלר).
- **דוגמה לקשר לשוני שאינו מוכיח מניע:** גלר הוא צורה של הלר, ששמו עשוי להתפרש מן הגרמנית כ״בהיר״. אין בכך הוכחה שאריה בהיר בחר בשם כתרגום מכוון.
- **דוגמאות לשמות גאוגרפיים:** ליבשיץ, רקנאטי וטברסקי. כשיש כמה מקורות אפשריים מציגים את החלופות.
- **שמות שעדיין דורשים מחקר אטימולוגי:** ציזלינג, בנטוב, טבנקין, ארגוב, אסף, נורוק ומיקוניס. בחלקם התווסף מידע ביוגרפי, אך סטטוס האטימולוגיה נותר `unknown`.
- **כלל עריכה:** `verified` מציין ביסוס של פירוש השם הכללי או הקשר הלשוני המתועד, ולא בהכרח הוכחה לסיבה האישית לבחירת השם או לשושלת של חבר הכנסת.

**היקף:** מספר הרשומות אינו בהכרח מספר חברי הכנסת הייחודיים, וטרם אומתה כאן השלמת כיסוי מלא של כל חברי הכנסת הראשונה.

## מבנה המאגר

הנתונים נמצאים ב־`data/surnames.json`. כל רשומה כוללת:

- `id` — מזהה ייחודי וכתובת דף השם.
- `name`, `latin` — שם בעברית ובאותיות לטיניות.
- `status` — רמת התיעוד.
- `meaning`, `history` — פירוש ורקע קצרים.
- `sources` — מערך קישורים עם `title` ו־`url`.
- `linguisticOrigin`, `historicalCommunities`, `geographicAssociation` — נתוני מקור, אם אומתו.
- `alternateSpellings` — כתיבים חלופיים שנבדקו.
- `metadataNote` — סייגים והבהרות מחקריות.

הוספת שם נעשית בעריכת קובץ הנתונים; הממשק טוען את הרשומות ממנו.

## פיתוח מקומי

נדרש Node.js עם npm.

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

הפקודה `npm run build` יוצרת את תיקיית `dist`.

## משימות המשך

1. **בדיקת שמות מקוריים ועברותם:** להשוות כתיבים היסטוריים ומשמעות לשונית ולחפש עדות ישירה למניע שינוי השם.
3. **הצלבת מקורות עצמאיים:** בפרט שמות שנסמכים כרגע על `Dictionary of American Family Names` בלבד, כולל בדיקה בערכים ייעודיים של מוזיאון אנו ומקורות מחקר נוספים.
3. **ביקורת כתיבים חלופיים:** לאמת כל וריאנט בנפרד ולהבדיל בין תעתיק, שם נגזר ושם בעל מקור נפרד.
4. **בקרת איכות:** לוודא התאמה בין `status` לבין חוזק המקורות; לתקן קישורים שבורים ונתונים חסרים.
5. **הרחבת המאגר:** הוספת שמות חדשים בקבוצות קטנות, עם פירושים קצרים וקישורים בדוקים.
6. **שיפור נגישות ובדיקות:** בדיקת חיפוש, ניווט, תצוגת מובייל וקריאות.
7. **תכונות עתידיות, טרם אומתו כממומשות:** PWA להתקנה ולעבודה לא מקוונת, הקראה, וחיבור מבוקר למקורות כגון Wikidata, בכפוף לאיכות הנתונים ולתנאי הרישיון.
