# שורשי המשפחה — Family Name Origins

יישומון מחקרי בעברית לפירוש שמות משפחה ולהיסטוריה שלהם, עבור שמות יהודיים בעולם וכלל הקבוצות באוכלוסיית ישראל.

## מצב הפרויקט
שלד ראשוני עם חיפוש בעברית ובאנגלית, ארבע רשומות הדגמה, קישורי מקורות ורמות ודאות. עדיין לא הושלם אימות הרשומות, PWA או יבוא מוויקינתונים.

## פיתוח מקומי
`npm install` ואז `npm run dev`.

## פריסה ב־Vercel
ייבוא מאגר GitHub; Framework: Vite; Build command: `npm run build`; Output directory: `dist`.

## עקרונות המחקר
אין להציג פירוש שם כעובדה ללא מקור מחקרי. שמות ללא מקור יסומנו כלא מאומתים. אין להסיק מוצא משפחתי משם בלבד. אין להעתיק מאגרי צד שלישי ללא רישיון מתאים.

## המשך
מחקר 20 שמות, סיומות, תעתיקים, מקורות לכל טענה, חיבור ל־Wikidata, הקראה ו־PWA.
